# 同梱版のインストールと初回設定（初心者向け）

[ユーザーガイド](USER_GUIDE.md) · [トラブルシューティング](TROUBLESHOOTING.md)

導入・初回処理の前に[利用上の注意・免責事項・外部サービス規約の確認](TERMS_AND_DISCLAIMER.md)を確認してください。APIの契約・使用は一律必須ではありません。利用する機能・サービスは、利用者が個別に選択します。

同梱版は、GUI・動画変換worker・Python実行環境・ライブラリ・FFmpegをまとめた配布版です。**利用者のPCへのPython、Git、winget、Homebrewの導入や、PowerShell・環境変数の操作は不要です。**

同梱版を利用できるのは、担当者がビルド・検証し、リリースの添付ファイルを公開した後です。ソースコードにビルド機能が追加されただけでは、配布ファイルが公開済みという意味ではありません。配布ファイルがない場合は、担当者に公開状況を確認してください。

## 1. 用意するものとダウンロード

- 対応PC：Windows 11 x64、またはmacOSの対応CPU・OS
- インターネット接続、十分な空き容量、電源
- Geminiを使う場合は利用を許可されたGoogleアカウントとAPIキー
- ソフトウェア導入と外部サービスへ講義テキストを送信する許可

同梱版でも、Gemini・DeepLの翻訳、Azure AI Speechを選択した場合の音声生成にはネット接続が必要です。標準のPiper音声生成はPC内で行い、音声モデルも同梱されています。文字起こしモデルは初回の利用時にダウンロードします。料金・情報の取扱いは[ユーザーガイド](USER_GUIDE.md#1-はじめに)を確認してください。非公式Edge TTSとXTTSは削除しました。

同梱版には、映像内の文字をOCRで読み取って英語へ置き換える機能は含みません。音声の吹き替え・字幕の生成と埋め込みは利用できます。

1. 担当者から案内された版を、[公式GitHub Releases](https://github.com/yosuke0793/ondemand_translater/releases)から取得します。
2. リリースの注意事項に「対応OS」「署名・検証状況」があるか確認します。
3. 「Assets」（添付ファイル）を開き、お使いのPC用のファイルを選びます。
4. Windowsは `windows-x64` のセットアップ `.exe`、MacはCPUに合う `.dmg` をダウンロードします。MacのAppleメニュー→「このMacについて」でMシリーズなら `arm64`、Intelなら `x86_64` を選びます。
5. 「Source code (zip)」「Source code (tar.gz)」は開発用のソースです。初心者向け同梱版ではありません。

`-ffmpeg-source.tar.gz` は同梱FFmpegと依存ライブラリの対応ソースです。通常のインストールには使いませんが、同じ版の配布ページで取得できるようにしています。古い試作版のApple Silicon用FFmpegは再配布不可の構成だったため、配布者は自前ビルドへ置き換えた版だけを案内してください。

手動ビルドのGitHub Actions成果物や公開前のドラフトは、一般利用者向けの正式公開版とは別です。内容が分からない場合は担当者が検証した版の案内を受けてください。

## 2. Windowsにインストールする

1. エクスプローラーの「ダウンロード」を開きます。
2. ダウンロードしたセットアップ `.exe` をダブルクリックします。
3. インストーラーの案内を読み、インストール先などを確認して進めます。標準では現在のユーザー用に導入します。
4. インストールが完了したら、スタートメニューの「Translate Service」から起動します。作成したショートカットからも起動できます。
5. Translate Serviceの画面と、タイトルのバージョン表示を確認します。

既存のPythonやFFmpegは削除・変更しません。セットアップが配置したファイルを個別に移動したり、workerのexeだけを実行したりしないでください。

SmartScreen等の警告は、署名・評判情報が不足した配布物で表示されることがあります。**一律に警告を無視せず**、公式の取得先・担当者の案内・署名状況を確認してください。組織のPCでは管理者へ相談し、セキュリティ機能全体を無効化しないでください。

## 3. Macにインストールする

1. Finderの「ダウンロード」を開きます。
2. CPUに合った `.dmg` をダブルクリックします。
3. 開いた画面の `TranslateService.app` を「Applications」（アプリケーション）のアイコンへドラッグします。
4. コピー完了後、ディスクイメージを取り出します。
5. Finderの「アプリケーション」からTranslate Serviceを起動します。
6. タイトルのバージョン表示を確認します。

**この同梱版はアプリケーションフォルダーへ移動できます。** 以前のソース版ランチャーはプロジェクトの `mac` フォルダーから起動する構成で、同じルールではありません。両者を混同しないでください。

未署名・未公証のビルドはmacOSにブロックされる可能性があります。配布ページの署名状況と担当者の案内を確認し、組織の規則に従います。Gatekeeperを全面無効化する操作は不要です。

## 4. APIキーを画面から登録する

初回起動時はAPIキー設定画面が自動で開きます。通常は次回以降も表示します。
画面下部の「次回から表示しない」をチェックすると、次回以降は自動表示しません。
後からメイン画面の「APIキー設定」を開き、チェックを外せば自動表示を再開できます。
この設定はAPIキーの保存・削除とは別です。

### キーを取得する

Gemini APIキーはアプリがGoogleのサービスを呼び出すための秘密の文字列です。Googleのパスワードとは別です。

1. アプリの「APIキー設定」を押します。
2. 「Google AI Studioでキーを取得」を押すか、[公式APIキー画面](https://aistudio.google.com/apikey?hl=ja)をブラウザで開きます。
3. 利用を許可されたGoogleアカウントでログインし、規約・料金・割り当てを確認します。
4. 使用できるキーを用意してコピーします。詳細は[APIキーの取得手順](INSTALL_WINDOWS.md#5-1-キーを用意する)と[取得時のトラブル](TROUBLESHOOTING.md#gemini-apiキーの取得画面で進めない)を参照してください。取得はOS共通です。

### 保存する

1. アプリへ戻り、APIキー設定画面の `gemini` 欄へキーを貼り付けます。入力文字は隠して表示されます。
2. 引用符を付けず、前後に空白や改行がないようにします。
3. その欄の「保存」を押します。
4. 「保存完了」と「保存済み」を確認します。入力欄は保存後に空になりますが、保存済みキーを消した意味ではありません。
5. 「閉じる」を押します。PCのサインアウトやアプリ再起動は不要です。

Windowsでは資格情報マネージャー、Macではキーチェーンを使います。キーを通常の設定JSON、ジョブJSON、ログに保存しません。OSからアクセス許可を求められたら、アプリと操作内容を確認します。保存先が使えない場合はエラーになり、平文ファイルへの代替保存は行いません。

### 音声合成を選ぶ：PiperとAzure AI Speech

初めはメイン画面の「音声合成方式」を **Piper（ローカル・TTS外部送信なし）** にしてください。Piperの音声生成にはアカウント・APIキー・従量料金が不要です。翻訳用のGemini等の設定とは別です。

メイン画面の「音声」欄をクリックすると、**女性（LJ Speech）** と **男性（John）** を選べます。どちらも米国英語で、新しい同梱版には両方のモデルが入っています。最初は女性の声が選ばれています。選んだ声は次回の起動時も復元されます。声を変えても、すでに登録したジョブの設定は変わらないため、変更後に新しいジョブを登録してください。

より多くの英語音声を使いたい場合は **Azure AI Speech（公式API・従量課金）** を選択できます。これは非公式Edge TTSを有料化したものではなく、利用者が契約したAzure Speechリソースの公式APIを使う方式です。

1. 所属大学の担当者に、Microsoft Azureの契約、英語字幕の外部送信、費用負担を確認します。個人で契約する前に組織の手順を確認してください。
2. 「APIキー設定」の「Azureポータルを開く」を押し、許可されたアカウントでログインします。
3. Azureのサブスクリプションを用意し、ポータルで **Speechサービス（音声サービス）** のリソースを作成します。表示名・画面構成は変更される場合があります。[公式のリソース準備手順](https://learn.microsoft.com/ja-jp/azure/ai-services/speech-service/overview#create-a-speech-resource)も参照してください。
4. リソースの料金レベル・リージョンを選びます。無料枠が表示されても、上限・対象音声・有料利用への条件を必ず確認します。リソースを作るだけで本アプリの費用上限が設定されるわけではありません。
5. 作成したリソースを開き、「キーとエンドポイント」等の画面からキーとリージョンを確認します。MicrosoftアカウントのパスワードやGeminiのキーとは別です。
6. アプリの「APIキー設定」で `azure` 欄へキーを貼り付け、その行の「保存」を押します。
7. 「Azureリージョン」欄へ、同じリソースの識別子（例：`japaneast`）を入力し、その行の「保存」を押します。「東日本」などの表示名や `https://...` のURLは入力しません。リージョンは秘密情報ではなく通常の設定として保存します。
8. 設定画面を閉じ、メイン画面でAzure AI Speechと英語音声を選択します。音声の対応状況はリージョンによって異なるため、まず短い動画で試します。
9. ジョブ追加時の「Azure Speechの利用確認」を読み、外部送信と料金を確認した場合のみ「はい」を押します。

Azureを選んだ場合、入力済み英語SRTでも音声生成にキー・通信が必要です。失敗してもPiperや非公式サービスへ自動で切り替えません。Piperで再処理したい場合は、保存した英語SRTを指定し、Piperを選んで新しいジョブを登録してください。

Azureの「音声」欄にも男性・女性を表示しています。例えば、**男性はAndrew**、**女性はAria** を選べます。音声名の説明に「男性」「女性」と表示されるので、それを目印にしてください。音声合成方式を切り替えた直後は、その方式の既定の女性音声に戻ります。必要な声を選び直してからジョブを追加してください。

料金は[Azure公式料金表](https://azure.microsoft.com/ja-jp/pricing/details/speech/)で確認します。予算アラートが必ず利用を停止するとは限らず、本アプリにも自動の課金上限はありません。キーを他人へ配布したり、リポジトリへ貼り付けたりしないでください。

保存済みのキーの値は画面で再表示しません。変更する場合は新しいキーを入力し「保存」、削除する場合は該当サービスの「削除」を押します。削除はOSに保存したキーだけが対象で、提供元での失効・契約変更ではありません。

**以前に環境変数でキーを設定している場合、その値が優先されます。** 「環境変数を使用中」と表示された場合、担当者へ解除・更新を相談してください。保存した新キーと違うキーが使われる原因になります。

DeepLを使う場合は `deepl` 欄に対応するAPIキーを保存し、メイン画面の翻訳方式を `deepl` にします。現行の送信先はAPI Free用です。Argosや英語SRTでの再開では、翻訳APIキーが不要な工程もありますが、標準音声生成の通信は必要です。

キー未設定のまま通常の翻訳ジョブを追加すると、登録前に通知して設定画面を開きます。保存した後は、自分で「翻訳開始(キューに追加)」をもう一度押してください。

## 5. 初めての動画を処理する

[ユーザーガイドの初回処理](USER_GUIDE.md#3-初めての動画を処理する)に従います。最初は機密情報を含まない短いMP4で確認します。

- 初回の文字起こしではモデル取得に時間がかかります。アプリを閉じたりスリープさせたりしないでください。
- 完了後は英語音声・字幕・末尾までの再生を確認します。
- 同名入力を同じ出力先へ再実行すると、成果物を上書きする可能性があります。
- APIキーを後で変更・削除した場合、待機ジョブは実行開始時点の有効なキーを使います。エラーになったジョブは自動再試行されません。

## 6. 保存場所・更新・アンインストール

| OS | 同梱版の標準データ場所 |
|---|---|
| Windows | `%LOCALAPPDATA%\TranslateService\` |
| macOS | `~/Library/Application Support/TranslateService/` |

完成動画はGUIで選んだ出力先です。設定・ジョブ履歴・中間データはアプリ本体とは別に保存するので、アプリを更新しても保持します。APIキーはOSの保存先にあり、データフォルダーのバックアップには含まれません。モデルのキャッシュが別の場所に作られることもあります。

配布物には過去のジョブ・ログ・利用者の設定を含めません。同じPCで以前にソース版や試作版を使っていた場合は、PCに残るデータから過去の履歴が表示されることがあります。再インストール時に自動削除しません。新規ユーザーの空のデータ領域では履歴は空です。

更新時は、全ジョブが終わってからアプリを終了し、完成物・用語・データをバックアップします。Windowsは新しいセットアップを実行し、Macは新しいアプリへ置き換えます。新旧アプリを同じデータ場所で同時起動しないでください。ダウングレードや別OSへの履歴移行を保証するものではありません。

Macの旧ソース版は `source/worker/data/` を使っていたため、同梱版へ切り替えると以前の履歴が見えない場合があります。用語は旧版の「CSV書出」から新版の「CSV読込」へ移せます。履歴やDBを手動で混ぜないでください。Windowsの旧版は標準場所が共通なので、旧版を停止してから切り替えます。

アンインストール前に、不要な保存済みAPIキーをアプリの設定画面で削除します。Windowsは「設定」→「アプリ」→「インストールされているアプリ」からTranslate Serviceを削除し、Macはアプリケーションフォルダーのアプリをゴミ箱へ移します。**動画・データ・OSの保存済みキーを自動一括削除する操作ではありません。** データの整理は[ユーザーガイド](USER_GUIDE.md#8-保存場所と不要データの整理)を参照します。

## 7. 困ったとき

- 「同梱の変換プログラム／動画処理ツールが見つかりません」：アプリの一部が移動・削除された可能性があります。正式な配布物を再インストールしてください。PCのPythonを追加して直す必要はありません。
- OSのAPIキー保存先にアクセスできない：キーチェーン／資格情報のアクセス許可、組織の規則を担当者に確認します。平文保存へ切り替えないでください。
- 保存したキーで認証に失敗する：環境変数の優先、選択した翻訳方式、提供元のキー・割り当てを確認します。キーの保存成功はAPI認証成功を保証しません。
- ジョブがエラーになる：データ場所の `jobs/<Job ID>/status.json` と `logs/<Job ID>.log` を確認します。

問い合わせにはOS・CPU・**タイトルに表示されたアプリのバージョン**・Job ID・秘密情報を除いたエラーを添えます。[トラブルシューティング](TROUBLESHOOTING.md)も参照してください。
