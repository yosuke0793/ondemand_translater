## 1. はじめに

### できること・できないこと

| 項目 | 内容 |
|---|---|
| 入力 | 音声の入った `.mp4` 動画。拡張子を変えるだけでは他形式から変換できません |
| 処理 | 日本語の文字起こし、日本語字幕の整形、英語への翻訳、英語音声生成、動画への結合 |
| 出力 | 英語音声付きMP4、英語SRT、日本語SRT |
| 字幕 | 通常はMP4の字幕トラックとして埋め込み。プレーヤーで表示を切り替えます |
| 実行 | PC上のアプリで実行。サーバーへのジョブ投入やブラウザでの操作は不要 |
| 非対応・制限 | GUIでは他言語への翻訳、字幕焼き込みの選択、映像内の日本語文字の置換はできません |

映像に元から写っているスライドや看板の日本語は、通常のGUI操作では英語になりません。翻訳・文字起こしは自動処理のため、固有名詞、専門用語、数値などを必ず人が確認してください。音声のタイミング調整により字幕時刻が入力字幕と変わる場合があります。

### 利用前の重要な注意

- **完全なオフラインアプリとは限りません。** 標準のGemini翻訳は日本語字幕のテキストをGoogleへ送ります。標準のPiper音声合成はPC内で行い、英語字幕を外部へ送りません。Azure AI Speechを選ぶと英語字幕をMicrosoft Azureへ送ります。
- DeepLを選ぶと翻訳テキストをDeepLへ送ります。必要なモデルを準備済みのArgos＋Piper、または英語SRT入力＋Piperでは、翻訳・音声合成の外部サービスは不要です。
- 初回は文字起こしモデルなどのダウンロードがあります。通信できる環境で使ってください。
- 機密情報、個人情報、公開前の講義を処理する前に、所属先の規則と各サービスの利用条件を確認してください。
- APIの料金・利用上限は提供元の契約に依存します。アプリには料金表示や予算上限の設定機能がありません。
- 元動画は手元に保管してください。完成動画の音声は英語音声になるため、原本の代わりにしないでください。
- アプリを別の組織や第三者へ渡す場合は、アプリ本体だけをコピーせず、ライセンス表示と対応するソース配布物も提供する必要があります。担当者は[配布ガイド](PACKAGING.md)を確認してください。アプリで作ったという理由だけで完成動画がGPLになるわけではありませんが、講義資料・出演者・元動画の利用許可は別に確認します。
- 長い動画は時間・メモリ・ディスク容量を消費します。処理中は入力動画のコピー、音声、中間動画を作ります。完成動画1本分だけの空き容量では足りない場合があります。
- 電源に接続し、PCがスリープしないようにしてください。画面を閉じての処理継続は保証されません。

## 2. インストールする

お使いのPCに合わせて、次のどちらかを最初から進めてください。

- **公開済みの同梱版を利用する方**：[同梱版のインストール手順](INSTALL_BUNDLED.md)。Python等の準備は不要で、APIキーは画面から保存します。
- 以下のOS別手順は、ソースコードから導入する従来方式です。
- **Mac**：[macOSインストール手順](INSTALL_MAC.md)
- **Windows**：[Windowsインストール手順](INSTALL_WINDOWS.md)

インストール済みなら次へ進みます。同梱版はMacの「アプリケーション」／Windowsのスタートメニューから起動します。ソース版はMacではプロジェクトの `mac` フォルダー内の `TranslateService.app`、Windowsではデスクトップの「Translate Service」ショートカットから起動してください。ソース版のexe直接起動は推奨しません。

Windowsの更新版インストーラーは、複数のPythonがある場合も対応する導入先を探し、アプリ専用環境を検証します。通常の `python --version` が古い版でも、他のPythonを削除する必要はありません。非対応・破損したアプリ用環境は別名へ退避して作り直します。詳細は[WindowsのPython検出・修復](INSTALL_WINDOWS.md#pythonの自動検出と仮想環境の修復)をご覧ください。

同じPCで同時に複数のアプリを起動しないでください。同じ保存場所を複数のアプリで同時に操作する使い方には対応していません。

## 3. 初めての動画を処理する

最初は、機密情報を含まない短い動画で動作を確認しましょう。

### 手順1：出力用フォルダーを作る

1. Finder（Mac）またはエクスプローラー（Windows）で「書類」または「ドキュメント」を開きます。
2. 「新規フォルダー」を作り、「翻訳済み動画」など分かりやすい名前にします。
3. 初回はPC内のフォルダーを使ってください。外付けディスク、ネットワークドライブ、クラウド同期フォルダーは、切断や同期競合の原因になるため避けると切り分けが簡単です。

### 手順2：動画と出力先を選ぶ

1. Translate Serviceを起動します。
2. 「動画ファイル (.mp4)」の右にある「選択...」を押します。
3. 日本語音声のMP4動画を選び、ファイル選択画面の「開く」を押します。
4. 「動画出力先」の右にある「選択...」を押します。
5. 手順1で作ったフォルダーを選びます。欄にその場所が表示されたことを確認します。
6. 初めての通常処理では「日本語字幕 (.srt)」「英語字幕 (.srt)」を**両方空欄**にします。

入力ファイルを選ぶ欄と、保存するフォルダーを選ぶ欄は別です。動画ファイルそのものを出力先欄に指定しないでください。

### 手順3：設定を確認する

初回は次の設定で試します。

| 画面 | 初回の選択 |
|---|---|
| 翻訳 | `gemini`。インストール時にAPIキーを設定しておきます |
| 音声合成方式 | `Piper（ローカル・TTS外部送信なし）`。音声合成用APIキー不要 |
| 音声 | 「米国英語・女性（LJ Speech／ローカル）」 |
| 文字起こし | `balanced`。重い場合は `fast` で短い動画を試します |
| 専門用語 | 最初から入っている一覧のままで構いません |

### 手順4：開始して待つ

1. 「翻訳開始(キューに追加)」を**1回**押します。
2. ジョブ一覧に行が追加されたことを確認します。
3. 「状態」が「待機中」から「処理中」へ変わります。
4. 進捗と処理段階を見ながら待ちます。初回はモデルのダウンロードがあるため長くかかることがあります。
5. 「完了」、進捗「100%」になったら次へ進みます。

ボタンを繰り返し押すと別のジョブが登録されます。進捗率は作業段階に基づく目安であり、残り時間ではありません。文字起こしや音声生成では同じ数値が長時間続くことがあります。

### 手順5：完成ファイルを確認する

1. ジョブ一覧の完了した行をクリックします。
2. 「完了ファイルを開く」を押します。行のダブルクリックでも同じ操作になります。
3. Finderまたはエクスプローラーで完成動画が選択された状態になります。**このボタンは動画を自動再生するボタンではありません。**
4. 選択された動画をダブルクリックし、普段の動画プレーヤーで再生します。
5. 音声が英語であること、字幕をオンにすると英語が表示されること、末尾まで再生できることを確認します。

元動画が `lecture.mp4` なら、通常は次の3ファイルが同じ出力先にできます。

```text
lecture_translated.mp4       英語音声・英語字幕付き動画
lecture_translated.srt       英語字幕
lecture_translated_ja.srt    日本語の文字起こし字幕
```

**英語SRTだけを入力した場合、日本語字幕の出力は空ファイルになることがあります。** 日本語の文字起こしをスキップするためです。日本語字幕も必要なら動画だけで処理するか、日本語SRTも指定してください。

### 字幕の表示と上書き

- 埋め込み字幕は再生ソフトによって自動表示されません。プレーヤーの「字幕」「Subtitles」などのメニューから英語字幕を選びます。
- 字幕トラックを扱えないプレーヤーでは、別の対応プレーヤーで再生するか、出力した英語SRTを読み込んでください。例として[VLCの公式サイト](https://www.videolan.org/vlc/)から入手したプレーヤーを使えます。
- **同じ元ファイル名を同じ出力先へ処理すると、既存の完成動画・字幕を確認なしで上書きする可能性があります。** 別の設定で比較する場合は「翻訳済み動画_別音声」など別フォルダーを指定してください。
- 別フォルダーにある同名の入力動画も出力名が重複します。ジョブIDは異なっていても、出力ファイル名にIDは付きません。

## 4. 画面と設定の説明

| 項目 | 役割・注意 |
|---|---|
| 動画ファイル (.mp4) | 処理する原本。登録時に作業用コピーを作ります |
| 動画出力先 | 完成動画と字幕を保存するフォルダー。次回起動時も復元されます |
| 日本語字幕 (.srt) | 任意。文字起こし済みの字幕がある場合に指定 |
| 英語字幕 (.srt) | 任意。翻訳済みの字幕がある場合に指定 |
| 専門用語 | 文字起こしのヒント。1行に1用語 |
| 翻訳 | `gemini`、`deepl`、`argos` を選択 |
| 音声合成方式 | Piper（標準・PC内処理）／Azure AI Speech（公式API・外部送信・従量課金）。次回起動時も復元 |
| 音声 | 男性・女性を選択。Piperは女性LJ Speech／男性John、Azureは女性Aria／男性Andrewなど。選択は次回も復元。方式を切り替えるとその方式の既定の女性音声に戻ります |
| 文字起こし | 速度と精度のプリセット |
| APIキー設定 | Gemini／DeepL／Azure SpeechのキーをOSの安全な保存先へ登録・削除。Azureリージョンも設定。値を再表示しません |
| チェックしたジョブをキャンセル | 一覧左端のチェックが付いた待機中／処理中ジョブに停止を要求。履歴・データは保持 |
| チェックしたジョブを削除 | 停止済みのチェック対象の履歴・ログ・中間データを削除。完成動画・出力字幕は保持 |
| 全ジョブの中間データを削除 | 処理中・待機中のジョブがないとき、コピー入力・中間音声・中間字幕などを一括削除。履歴・ログ・完成動画・出力字幕は保持 |
| ジョブ一覧 | ID、入力名、状態、進捗、処理段階、登録日時、出力先を表示 |

声はジョブ登録時に保存されます。声の選択を変えても、登録済みジョブや完成済み動画は変わりません。声を変更した動画を作るには、声を選び直して新しいジョブを追加してください。新しい同梱版のPiperは男女両方のモデルを含み、どちらも音声生成時に外部送信しません。

### 翻訳の選び方

| 選択 | APIキー | 通信・補足 |
|---|---|---|
| `gemini` | `GEMINI_API_KEY` が必要 | Googleの翻訳用APIへテキストを送信。起動時の既定 |
| `deepl` | `DEEPL_API_KEY` が必要 | 現行版はDeepL API Freeの送信先を使用。通常のDeepLアプリ契約やAPI Proのキーをそのまま使えるとは限りません |
| `argos` | 不要 | PC内で翻訳。翻訳モデルが未導入なら初回にダウンロード。結果の品質を確認してください |

英語SRT指定で翻訳工程をスキップする場合、通常は翻訳APIを呼びません。ただし英語音声生成の通信は行います。

### 文字起こしの選び方

| 選択 | 特徴 |
|---|---|
| `fast` | `small` モデル。軽さ・速度を優先 |
| `balanced` | `medium` モデル。起動時の既定 |
| `high-accuracy` | `large-v3` モデル。精度重視ですが時間・メモリ消費が増えます |

精度向上を保証する設定ではありません。音声の質によっては誤認識が残ります。まず短い動画で比較してください。

出力先・音声・ユーザー追加用語は保存されます。**翻訳方式と文字起こし設定は、再起動時に `gemini` と `balanced` に戻ります。** 毎回確認してください。登録済みジョブの設定は、画面で後から設定を変えても変わりません。

APIキー設定の操作は[同梱版の初回設定](INSTALL_BUNDLED.md#4-apiキーを画面から登録する)を参照してください。キーは通常の設定ファイルへ保存せず、worker起動時に必要なサービスのキーだけを環境として渡します。環境変数のキーがある場合はそちらが優先されます。

APIキー設定画面は起動時に自動表示します。「次回から表示しない」をチェックすると、次回以降は自動表示しません。メイン画面の「APIキー設定」からいつでも開けます。チェックを外すと次回から再び自動表示します。

## 5. 複数の動画・キャンセル・終了

### 複数動画を登録する

1. 1本目を登録します。
2. 次の動画を選び、必要なら出力先・設定を変えて登録します。
3. 同じ操作を繰り返します。1回の選択画面での複数ファイル一括登録ではありません。
4. 登録順に1本ずつ処理されます。一覧は新しい登録が上に表示されるため、表示順と実行順は逆になることがあります。

登録後は動画・日本語字幕・英語字幕の選択欄が空になります。次のジョブへ字幕を意図せず流用しないための動作です。出力先と変換設定は残るので、次の登録前に確認してください。

### 状態の意味

| 表示 | 意味 | 次にすること |
|---|---|---|
| 待機中 | 順番待ち | アプリを開いたまま待つ |
| 処理中 | 変換中 | 進捗・処理段階を確認。PCをスリープさせない |
| 完了 | 出力保存と不要動画の削除が完了 | 完成動画と字幕を確認する |
| エラー | 変換・保存・削除などの失敗 | [トラブルシューティング](TROUBLESHOOTING.md)でログを確認 |
| キャンセル | 取り消されたジョブ | 再実行する場合は新しく登録 |

エラーになったジョブでも、完成動画が出力先に存在する場合があります。コピー後の字幕保存や動画削除で失敗する場合もあるため、「動画がある」だけで正常完了と判断しないでください。

### キャンセルする

ジョブ一覧左端の「対象」チェックボックスをオンにし、「チェックしたジョブをキャンセル」を押します。複数件を指定できます。待機中・処理中のジョブが対象です。完了済みの出力を消すボタンではありません。

処理中のキャンセルは停止要求です。別途起動された処理がすぐにすべて終了する保証はありません。すぐに作業フォルダーを削除したり、同じ保存場所で別のアプリを起動したりしないでください。キャンセル・エラーのジョブでは作業用動画が残ります。

### アプリを終了する

できるだけ全ジョブが完了してから、ウィンドウを閉じてください。

- ウィンドウを閉じると、実行中の変換プロセスへ停止要求を送ります。**閉じた後も自動的に完了まで処理する運用には対応していません。**
- 待機中のジョブは保存され、次回起動時に処理対象になります。
- エラー・キャンセルのジョブをGUIからそのまま再実行するボタンはありません。元動画を選び直して新しく登録してください。
- 強制終了後の復旧処理はありますが、途中段階からの自動再開・二重実行の防止を常に保証するものではありません。復旧時は一覧とログを確認します。

## 6. 字幕から途中再開する

途中再開とは、**新しいジョブへ元動画と既存の字幕を登録し、字幕がある工程をスキップすること**です。「失敗したジョブを自動修復する」機能ではありません。

| 入力の組み合わせ | スキップする処理 | 実行する主な処理 |
|---|---|---|
| 動画のみ | なし | 文字起こしから全工程 |
| 動画 + 日本語SRT | 文字起こし | 日本語整形、翻訳、音声生成、動画結合 |
| 動画 + 英語SRT | 文字起こし、日本語整形・翻訳の実質的な生成処理 | 英語音声生成、動画結合 |
| 動画 + 日本語SRT + 英語SRT | 文字起こし、英語字幕の再翻訳 | 英語音声生成、動画結合。日本語字幕も引き継ぐ |

工程名が画面やログに表示されても、既存ファイルがあるため工程内部で生成をスキップする場合があります。

1. 元のMP4動画を選びます。
2. 利用する日本語SRTまたは英語SRTを選びます。
3. 比較用なら、以前の結果と違う出力フォルダーを指定します。
4. 音声などの設定を確認し、新しく登録します。

SRTは字幕番号・開始終了時刻・本文を持つファイルです。本文だけのテキストを `.srt` に名前変更しても使えません。対象動画と対応する字幕をUTF-8で用意し、時刻や本文を確認してください。過去の出力SRTや失敗ジョブの中間SRTを利用できますが、原本は別の場所へコピーして保管することを推奨します。

## 7. 専門用語を登録する

専門用語は**Whisperの日本語文字起こしへのヒント**です。「必ずこの訳語に置換する」翻訳辞書ではありません。日本語字幕・英語字幕を指定して文字起こしを省略する場合、このヒントによる文字起こし改善は行われません。

### 画面から追加する

1. 「専門用語」欄には、既定のCSVを読める環境では工学用語が入っています。空の場合は[トラブルシューティング](TROUBLESHOOTING.md#6-出力字幕用語の問題)を確認します。
2. 欄の末尾へ移動し、改行して用語を追加します。1行に1用語を書きます。
3. 「一覧確認」で現在のリストを確認します。この別画面は閲覧用です。
4. ジョブ登録時または正常なアプリ終了時に、追加用語が保存されます。

用語は重複を除いて扱われます。全用語が必ず認識処理へ渡るとは限りません。初期プロンプトには長さの制限があります。

### CSVを使う

- 「CSV読込」：ファイルの用語を既存一覧へ追加します。既存リストを置き換えません。
- 「CSV書出」：画面上のリストをファイルへ保存します。別PCへ渡す、バックアップする場合に便利です。

次のような1列のUTF-8 CSVを使います。先頭の `term` は見出しです。アプリから書き出すCSVはUTF-8 BOM付きです。

```csv
term
有限要素法
ヤコビアン
```

表計算ソフトで保存する場合は「CSV UTF-8」形式を選びます。文字化けする場合は[トラブルシューティング](TROUBLESHOOTING.md)を確認してください。CSVでは各行の最初の空でない項目を用語として読むため、多列の翻訳辞書形式は推奨しません。

追加用語を減らすには画面の専門用語欄から該当行を削除して正常終了します。ただし既定の工学用語は次回起動時に再読込されます。既定用語の恒久的な変更は開発者向けです。

## 8. 保存場所と不要データの整理

### GUIから中間データを一括削除する

ジョブを個別に操作する場合は一覧左端の「対象」チェックボックスをクリックします。複数件をチェックでき、一覧更新後も保持します。行を選んでスペースキーでも切り替えられます。行の選択（完成ファイルを開くための操作）とは別です。

「チェックしたジョブをキャンセル」は停止要求であり、履歴削除ではありません。完了済みなど操作できないジョブは結果通知で件数を案内します。「チェックしたジョブを削除」は履歴・ログ・中間データを削除し、取り消せません。処理中・待機中を含む場合は先にキャンセルし、停止完了を待ってください。完成動画・出力字幕は保持します。別インスタンスは終了してから実行してください。

全ジョブを完了またはキャンセルし、他のアプリインスタンスも終了してから「全ジョブの中間データを削除」を押します。確認画面で削除を承認すると、ジョブ内のコピー入力動画・中間音声・中間字幕・一時プロンプトなどを削除します。エラー／キャンセル済みジョブも対象です。処理中・待機中は削除できません。

履歴・ログ（ジョブ内の `pipeline.log` を含む）・状態情報・完成動画・出力字幕・元の入力動画・設定・用語・APIキーは保持します。モデルキャッシュも削除しません。削除は取り消せず、中間字幕を使う途中再開には利用できなくなります。失敗時は一部が削除済みの場合があるため、表示されたエラーを確認してください。

### 完成物と作業データは別の場所です

完成動画・出力字幕はGUIの「動画出力先」に保存します。別に、アプリは作業・設定用のデータフォルダーを持ちます。

| 起動方法 | 標準のデータフォルダー |
|---|---|
| Macのソース版アプリをFinderから起動 | プロジェクト内の `source/worker/data/` |
| Macの同梱版アプリを起動 | `~/Library/Application Support/TranslateService/` |
| Macの起動スクリプトをターミナルから実行 | `~/Library/Application Support/TranslateService/` |
| Windowsのショートカットから起動 | `%LOCALAPPDATA%\TranslateService\` |

環境変数 `TRANSLATE_DATA_DIR` を設定している場合などは場所が異なります。MacのFinder用ランチャーはプロジェクト内のデータフォルダーを設定します。`source/data/` とは限りません。

Macでホーム配下の場所を開くにはFinderの「移動」→「フォルダへ移動...」へ上記パスを入力します。Windowsではエクスプローラーのアドレス欄へ `%LOCALAPPDATA%\TranslateService` を貼り付けてEnterを押します。`~` はホームフォルダー、`%LOCALAPPDATA%` はそのPCのユーザー用保存場所を表します。

### 残るデータ

| データ | 目的 | 通常の扱い |
|---|---|---|
| `settings.json` | 出力先・音声・APIキー画面の起動時表示設定（キー自体は含まない） | 保持 |
| `engineering_terms_custom.csv` | 追加した専門用語 | 保持・バックアップ |
| `jobs.db` | ジョブ履歴と状態 | 保持。削除すると履歴を失います |
| `queue/`、`processing/`、`done/`、`error/` | ジョブ管理用JSON | 自分で移動・削除しない |
| `jobs/<Job ID>/status.json` | ジョブ情報 | 保持 |
| `logs/<Job ID>.log`、ジョブ内 `pipeline.log` | エラー調査用ログ | 調査が終わるまでは保持 |
| ジョブ内の音声・字幕・本文 | 中間結果・再利用 | 正常完了確認後に整理可能 |

### 動画はいつ削除されるか

出力動画と字幕の保存がすべて成功した後、そのジョブフォルダー内の入力動画のコピー・中間動画・完成動画の重複コピーを自動削除します。

- GUIで指定した完成動画は削除しません。出力先がジョブフォルダー内の場合も保護します。
- 元の入力動画、別ジョブ、出力先の他の動画は削除しません。
- エラー・キャンセル時には動画を保持します。
- 削除が失敗するとエラーになります。
- この機能が入る前に完了した古いジョブを、起動時に一括整理することはありません。

### 動画以外を安全に整理する

1. 完成動画が末尾まで再生でき、必要な字幕が出力先にあることを確認します。
2. アプリを終了し、処理が動いていないことを確認します。
3. ジョブ一覧で控えたJob IDと一致する**正常完了済みのジョブフォルダーだけ**を開きます。
4. 必要なら別の場所にバックアップします。
5. 次の不要な中間ファイルを選んでゴミ箱へ移動します。フォルダー全体を一括削除しないでください。

主な削除候補は `audio.wav`、`en.mp3`、`en.mp3.meta.json`、`jp.srt`、`jp_clean.srt`、`en.srt`、`en_aligned.srt`、`en.txt`、`whisper_prompt.txt`、`video_text_regions.json`、残存する `.asr_chunks/`・`.tts_segments/` です。特に音声は容量削減に有効です。字幕・本文・プロンプトも内容を含むため、プライバシー上の整理対象になります。これらは使った機能によって存在しないこともあります。

**待機中・処理中・エラー・キャンセルのデータをこの手動手順で削除しないでください。** 終了済みの中間データ整理はGUIの「全ジョブの中間データを削除」、履歴も削除する場合は「チェックしたジョブを削除」を利用してください。

文字起こし・翻訳モデルのキャッシュはジョブフォルダー外に保存される場合があります。初心者向け手順では削除しません。削除すると次回に再ダウンロードが必要になります。

## 9. 更新・バックアップ・アンインストール

### バックアップ

出力動画・字幕、元動画、追加用語CSVを別のディスクなどへ保存します。ジョブ履歴も必要なら、アプリを終了してからデータフォルダー全体をコピーします。実行中の `jobs.db` だけをコピーする方法は避けます。

APIキーは動画や用語CSVに保存するものではありません。安全な認証情報管理方法を使ってください。

### 更新

同梱版は[同梱版の更新手順](INSTALL_BUNDLED.md#6-保存場所更新アンインストール)を参照してください。以下はソース版の更新手順です。

1. 全ジョブが終わるのを待ち、アプリを終了します。
2. 出力と追加用語をバックアップします。
3. ZIPで取得した人は新しいZIPを別フォルダーへ展開し、その場所でインストールし直します。古いフォルダーをいきなり削除しないでください。
4. Macではフォルダーが変わるとFinder起動時のデータ場所も変わります。「CSV書出」「CSV読込」で用語を移すのが簡単です。新しいアプリ側で出力先・音声を設定し直します。
5. Windowsは標準データ場所を共用しますが、ショートカットが新しい場所を指していることを確認します。
6. 新しいアプリで短い動画を処理し、問題がないことを確認します。

Gitで取得した人の更新コマンドは[開発者ガイド](DEVELOPER_GUIDE.md)にあります。作業フォルダーや仮想環境を別OS・別CPUのPCへそのままコピーしないでください。

### アンインストール

同梱版は[同梱版の削除手順](INSTALL_BUNDLED.md#6-保存場所更新アンインストール)を参照してください。以下はソース版の手順です。GUIで保存したAPIキーは、削除前に「APIキー設定」から不要なものを削除します。

1. 処理が終わってからアプリを終了します。
2. 元動画・完成動画・字幕・用語CSVを退避します。プロジェクト内へ出力していた場合は特に注意します。
3. Windowsはデスクトップの「Translate Service」ショートカットを削除します。MacはDockへ追加したショートカット等があれば外します。
4. 不要になった**このアプリのプロジェクトフォルダー**をFinder／エクスプローラーでゴミ箱へ移します。
5. Windowsの `%LOCALAPPDATA%\TranslateService\`、Macのホーム配下のデータはプロジェクト削除だけでは残ります。不要なら内容とパスを確認し、バックアップ後にそのアプリ専用フォルダーだけをゴミ箱へ移します。
6. APIキーが不要なら、[macOS手順](INSTALL_MAC.md)または[Windows手順](INSTALL_WINDOWS.md)の方法で設定を解除します。

Homebrew、Python、FFmpegは他のアプリでも使う可能性があるため、一緒に削除しないでください。外部サービス側で課金や契約が停止するわけではありません。不要なAPIキーや契約は提供元の管理画面でも整理します。

| ログ | 処理の経過やエラーを記録したファイル |
