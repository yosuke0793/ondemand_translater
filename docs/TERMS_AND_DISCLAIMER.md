# 利用上の注意・免責事項・外部サービス規約の確認

対象：Translate Service（ondemand_translater）の利用者・配布担当者

## 1. この文書の位置づけ

本アプリは、日本語講義動画の文字起こし、英訳、英語音声・字幕付き動画の作成を支援するツールです。主に大学教員・職員の利用を想定していますが、大学全体での一律利用や、特定の外部サービスの利用を義務付けるものではありません。

**どの機能・サービスを利用するかは、利用者が動画の内容、契約、料金、所属先の規則に応じて個別に選択します。** テスト段階のプログラムは開発・配布担当者本人から直接配布し、受け取った方は[テスト案内](TEST_USER_GUIDE.md)に沿って利用できます。導入や通常の開発元確認の警告について、毎回追加の許可を担当者へ求める必要はありません。

外部サービスへの送信可否や費用負担に不明点がある場合は、その点を担当者または所属先へ確認してください。担当者からの直接配布は、外部サービスの契約・動画の権利・所属先のルールを変更するものではありません。

この文書は、注意事項と既存のライセンス・外部サービス規約を説明するものです。法律相談、すべての用途についての適法性の保証、外部サービス提供者の承認を示すものではありません。また、閲覧だけで新たな契約への同意が成立したと扱うものではなく、ソフトウェアのライセンスに独自の用途制限を追加するものでもありません。

実際に適用されるソフトウェアライセンス、利用者の外部サービス契約、法令、所属先の規則が優先します。公式規約・料金は変更されるため、利用開始時および契約・機能変更時に確認してください。個別契約や契約時の規約が現在の公開ページと異なる場合があります。

## 2. 初めて使う方への確認事項

動画を登録する前に、次を確認してください。

- [ ] 元動画・講義資料を文字起こし、翻訳、音声合成する権限がある。
- [ ] 学生・教職員・第三者の氏名、顔、発言、成績、健康情報、未公開研究等の扱いを確認した。
- [ ] 選んだ翻訳・音声合成方式の通信先を理解した。
- [ ] 外部へ送るテキストについて、所属先の規則とサービス規約で送信・処理が認められている。
- [ ] 使用するアカウント・APIキーの契約者、利用権限、料金の負担者・上限を確認した。
- [ ] 元動画を保管し、出力先に同名ファイルがないか確認した。
- [ ] 完成後に、字幕・音声・映像を人が確認してから利用・公開する。

「非販売」「教育目的」「大学内」「無料」「公開済みの動画」は、それだけで利用条件を満たすことを意味しません。一方、これらの条件だけを理由に本アプリの使用を全面的に禁止するものでもありません。

## 3. 処理場所・外部送信と選択の自由

以下は標準GUIの処理です。開発者向けCLIの任意機能、第三者による改変版、利用者が追加するサービスには別途確認が必要です。

| 機能・選択肢 | 主な処理場所・通信 | 利用者が確認すること |
|---|---|---|
| 日本語文字起こし（faster-whisper） | PC内で音声を処理。モデル取得時には配布元への通信が発生 | モデルの利用条件、端末内データの保護、初回取得の許可 |
| 翻訳：Gemini | 日本語字幕等の翻訳用テキスト・指示をGoogleへ送信 | 無料／有料のデータ取扱い、利用資格、送信権限、料金 |
| 翻訳：Argos | 言語パック準備後はPC内で翻訳。パック取得は通信を伴う | 言語パックの利用条件と準備状況 |
| 音声合成：Piper | 英語字幕をPC内で音声化。同梱版は女性LJ Speech・男性Johnを同梱 | モデルの利用条件。ソース版は必要モデルの初回取得がある |
| 音声合成：Azure AI Speech | 英語字幕をMicrosoft Azureの公式APIへ送信 | Speechリソースの契約、リージョン、送信権限、料金 |

**Piperを選んでも、Gemini翻訳を選べば外部送信は発生します。** 翻訳・音声合成の外部サービスを使わない選択肢は、準備済みのArgos＋Piper、または翻訳済み英語SRT入力＋Piperです。モデル準備・更新の通信まで不要になるという意味ではありません。

字幕だけでも個人情報や機密情報を含むことがあります。Azureも標準GUIでは英語テキストを音声化し、本人の声のクローンを作る機能はありません。

## 4. 外部サービスごとの注意

### 4.1 共通

- サービスの利用は任意です。アプリの機能として表示されていることは、利用者の契約・動画内容での使用が承認されているという意味ではありません。
- 正規の契約・認証情報を使用し、認証、利用量制限、地域制限等を回避しないでください。
- 入力・出力の保存、学習・品質改善への利用、処理地域、委託先、削除条件はプラン・契約ごとに確認してください。「クラウドへ送ったデータは必ず即時削除される」とは保証しません。
- 大学が契約している場合も、対象者・用途・アカウント共有・API利用の範囲を確認してください。一般のWeb版契約がAPI契約を含むとは限りません。
- 次の要約は規約の全文ではありません。利用するサービスについて公式文書を確認してください。

### 4.2 Gemini API

[Gemini API追加利用規約](https://ai.google.dev/gemini-api/terms)（確認したページの発効日：2026年3月23日）および[Google APIs利用規約](https://developers.google.com/terms)を確認してください。

- 無料サービスでは、入力・出力が製品改善や機械学習技術の開発に利用され、人による確認が行われる場合があります。追加規約は、無料サービスへ機微情報・機密情報・個人情報を送らないよう定めています。
- 有料サービスはデータ取扱いが異なりますが、製品改善に使われないことと、一切保存されないことは同じではありません。不正利用対策等の保存・処理条件を確認してください。
- 無料／有料の扱いは、APIキーの見た目ではなく、プロジェクトの課金設定・契約等に依存します。地域による条件の違いもあります。
- 利用年齢、提供地域、禁止用途等の条件があります。特に未成年が使うアプリとして展開する場合、教職員向けの内部利用と同じ前提にはできません。

### 4.3 Azure AI Speech

Azure AI Speechは、非公式Edge TTSとは別の公式APIです。[Microsoft製品条項](https://www.microsoft.com/licensing/terms/)、利用者のAzure契約、[音声合成のデータ・プライバシー説明](https://learn.microsoft.com/en-us/azure/foundry/responsible-ai/speech-service/text-to-speech/data-privacy-security)を確認してください。

- 大学・個人のどちらの契約で使うか、Speechリソースを利用する権限、課金先、リージョンを確認してください。
- 入力英語テキストの外部送信を認められる場合だけ使用してください。リージョンの選択だけで所属先の要件を満たすとは限りません。
- 音声生成結果を本人の肉声・本人による発言の録音と誤認させないでください。元講師や発言者の同意・資料の権利も別に確認してください。
- 非公式Edge TTSおよびXTTSは現行版から削除しています。これらのサービス・モデルの利用許可を本アプリが取得したという意味ではありません。

## 5. 費用・APIキー

API利用料、ネットワーク料金、端末・保存容量等の費用は、利用者または契約上の負担者が確認・管理してください。

- 本アプリには正確な料金見積もり、請求表示、自動の支出上限による停止機能はありません。
- 無料枠、予算通知、キャンセル操作だけで、追加料金や既に発生した料金が必ず防げるとは限りません。再登録・再処理は追加利用量を生じ得ます。
- 少額・短い動画で動作を確認し、提供元の管理画面で利用量・予算を確認してください。
- APIキーをソースコード、配布物、字幕、ログ、スクリーンショット、問い合わせへ貼り付けないでください。
- 同梱GUIのキー保存はOS資格情報ストアを使用します。安全な保存先の使用は、端末感染・盗難・不正アクセスをすべて防ぐ保証ではありません。
- キー漏えいが疑われる場合は、サービス側で失効・再発行し、管理者へ連絡してください。アプリ内で削除するだけではサービス側のキーは失効しません。

## 6. 元資料・出演者・完成動画の取扱い

利用者は、対象資料と利用方法に応じて必要な許可・法的根拠を確認してください。

- 講義の録画許可と、翻訳・合成音声化・学外公開の許可は同じとは限りません。
- 引用画像、教科書、音楽、学生の発表、共同研究資料等は、元動画の利用許可とは別の条件がある場合があります。
- 著作権、個人情報、秘密保持、肖像・音声等の権利、所属先の公開基準を確認してください。
- 自動翻訳・合成音声を、実際に本人がその言語で発言した記録と誤認させないよう説明してください。例：「日本語講義を機械翻訳し、合成音声で英語化しています。内容は原講義と併せて確認してください。」
- 外部サービスの利用表示が必要な場合は、一般的な「機械翻訳」の表示とは別に、そのサービスの要件を満たしてください。

## 7. 出力の確認・データ保管

文字起こし、翻訳、字幕の時刻、音声には誤りがあり得ます。否定表現、専門用語、固有名詞、数値、単位、数式、話者の区別、著作物の引用等を確認してください。無音、欠落、重なり、映像・字幕とのずれも確認してください。

本アプリは成績判定、医療・法律判断、安全に関わる指示等の正確性を保証するものではありません。未確認の出力を、そのような判断の唯一の根拠にしないでください。

入力のコピー、音声、字幕、履歴、ログ等はPC内に残る場合があります。正常完了後の作業用動画の削除は、すべてのデータの消去、バックアップ・同期先の削除、復元不能な安全消去を意味しません。共有PC・同期フォルダーのアクセス権と保存期間を管理してください。

同名ファイルの上書き、中間データの削除、エラー・キャンセル、端末の故障等に備え、元動画を別に保管してください。詳しくは[ユーザーガイド](USER_GUIDE.md)の保存・整理手順を確認してください。
