# 協力者向けテストの案内（同梱版）

この文書は、開発・配布担当者から直接テストを依頼された方のための案内です。**テスト段階のプログラムは担当者本人からのみ配布します。** 受け取ったファイルを、この手順に沿ってインストールして試してください。プログラミングの知識は不要です。操作に迷った箇所も、テスト結果として担当者へお知らせください。

## 1. 最初に確認すること

- Windows版は未署名、Mac版はアドホック署名で、AppleのDeveloper ID署名・公証は未実施です。OSから警告される場合があります。
- macOSでは担当者が実機テストを完了しています。WindowsはActions上の自動テストに成功しており、今回は協力者のPCでの動作と使いやすさを確認します。
- Python、Git、Homebrew、wingetのインストールや、黒い画面でのコマンド入力は不要です。
- 組織のPCを使う場合は、ソフトウェア導入・外部サービス利用の許可を先に確認してください。
- テストは任意です。途中で中止しても構いません。起動できなかったことも有用な報告です。

次の順番で読みます。全部を一度に読む必要はありません。

1. この案内：受け取り方と確認する項目
2. [同梱版のインストールと初回設定](INSTALL_BUNDLED.md)：導入とAPIキー設定
3. [ユーザーガイド](USER_GUIDE.md)：通常の動画処理
4. [利用上の注意・免責事項](TERMS_AND_DISCLAIMER.md)：外部サービス・権利・料金の確認。処理を始める前に読んでください
5. [トラブルシューティング](TROUBLESHOOTING.md)：困ったときだけ参照

開発者ガイド・配布ビルド手順は読まなくて構いません。`INSTALL_WINDOWS.md`・`INSTALL_MAC.md`のソース版導入手順は、今回の同梱版には使いません。

## 2. 担当者からファイルを受け取る

担当者がActions成果物からダウンロードしたインストーラーを直接お渡しします。協力者は受け取ったファイルを使います。GitHubで配布物を探したり、実行のたびに担当者へ確認したりする必要はありません。

### Windows

1. 担当者から `TranslateService-0.1.0-windows-x64-setup.exe` を受け取り、PCに保存します。版が違う場合は、担当者が指定した `-setup.exe` を使います。
2. `-setup.exe` を直接受け取った場合、展開は不要です。ZIPに入れて渡された場合だけ、保存先で右クリックし、「すべて展開」→「展開」を押します。**ZIPの中から直接インストーラーを実行しないでください。**
3. 保存した、または展開先にある `-setup.exe` を確認します。
4. [Windowsへのインストール手順](INSTALL_BUNDLED.md#2-windowsにインストールする)へ進みます。

今回、`-portable.zip` は使いません。`TranslateWorker.exe` を単独で起動する必要もありません。

### Mac

1. 「このMacについて」でチップを確認します。Mシリーズは `macos-arm64`、Intelは `macos-x64` のファイルを受け取ります。
2. ZIPを受け取った場合は、Finderの「ダウンロード」でダブルクリックして展開します。
3. `.dmg` を直接受け取った場合はそのファイルを、ZIPの場合は展開先の `.dmg` を使い、[Macへのインストール手順](INSTALL_BUNDLED.md#3-macにインストールする)に従ってアプリケーションへコピーします。

### 実行しないファイル

| ファイル | 用途 |
| --- | --- |
| `-ffmpeg-source.tar.gz`、`-piper-source.tar.gz`、`-pyav-source.tar.gz` | ライセンスに基づいて提供する対応ソース。インストールには使いません |
| `-SHA256SUMS.txt` | ファイルが変わっていないか担当者が確認するための一覧 |
| `-build-info.json` | どのソースから作った版かを担当者が確認する記録 |

これらは担当者が案内するWeb上の共有先から取得できます。インストール・通常のテストではダウンロード不要で、インストーラーと一緒に受け取る必要もありません。テストでは直接受け取ったセットアップ／DMGを使い、正式なReleasesを探す必要はありません。

### 警告やブロックが出たら

未署名・未公証のため、初回に開発元を確認できないという警告が出る場合があります。**担当者から直接受け取ったテスト版は、次の個別許可手順で進めてください。追加の実行許可を担当者へ求める必要はありません。** 組織のPCでは、ソフトウェア導入についての組織のルールに従ってください。

#### Windows：SmartScreenの個別許可

1. 展開済みの指定された `-setup.exe` を通常のダブルクリックで起動します。「管理者として実行」は選びません。
2. 「WindowsによってPCが保護されました」というSmartScreen画面が出た場合は、「詳細情報」をクリックします。
3. 受け取ったセットアップの名前を確認します。未署名版の「発行元：不明な発行元」は、このテスト版では想定される表示です。
4. 「実行」をクリックし、インストーラーへ進みます。TranslateServiceの初回起動時にも同じSmartScreen画面が出た場合は、同様に「詳細情報」→「実行」で進めます。

「実行」がない、Smart App Control・組織のポリシーで拒否された、ウイルス対策が脅威を検出した、または管理者の資格情報を求められた場合は、そこで止めて担当者へ報告してください。DefenderやSmartScreenを無効にする設定変更、除外への登録、管理者実行による回避は行いません。

#### Mac：Gatekeeperの個別許可

1. DMGから「アプリケーション」へコピーした `TranslateService.app` を一度ダブルクリックします。
2. 「開発元を検証できない」「Appleは悪質なソフトウェアが含まれていないことを検証できません」など、開発元確認・未公証を理由とする警告が出たら、閉じます。
3. Appleメニュー→「システム設定」→「プライバシーとセキュリティ」を開き、下へスクロールします。古いmacOSでは「システム環境設定」→「セキュリティとプライバシー」→「一般」です。
4. TranslateServiceがブロックされたという表示の横にある「このまま開く」（版によっては「開く」）をクリックします。項目がなければ再度起動を試してから確認し、それでもなければ担当者へ報告します。
5. 確認画面で対象がTranslateServiceであることを確認し、「開く」を選びます。macOSが求める場合はTouch IDまたはMacへのログインパスワードで認証します。パスワードはアプリ・担当者へ渡しません。
6. アプリが起動したら通常の初回設定へ進みます。この操作は対象アプリの例外許可で、Gatekeeper全体の無効化ではありません。

「コンピュータに損害を与える」「マルウェア」「破損している」などの警告、組織による拒否、許可ボタンが使えない場合は、この手順で進めず担当者へ報告してください。ターミナルで隔離属性を削除する操作やGatekeeper全体の無効化は行いません。

開発元確認の警告が出ても、上記の操作で起動できればテストを続け、報告時に「警告あり・個別許可で起動」と記入してください。手順にない警告や起動できない場合は、表示内容を担当者へ知らせてください。画面画像では秘密情報を隠します。この手順は今回受け取ったテスト版についての案内です。

## 3. 最初の動画を処理する

1. 個人情報・秘密情報がなく、利用する権利のある、短い日本語音声のMP4を用意します。まずは30秒～2分程度で十分です。元動画は保管し、テスト用コピーを使ってください。
2. 出力用に新しいフォルダー（例：デスクトップの `翻訳テスト結果`）を作ります。既存の結果を上書きしないよう、他の動画とは分けます。
3. アプリを起動します。APIキーが必要な場合は、[画面からの登録手順](INSTALL_BUNDLED.md#4-apiキーを画面から登録する)に従います。
4. Geminiを選ぶ場合は、本人が利用を許可されたアカウント・APIキーを使い、規約・料金・割り当てを確認します。担当者や他人のキーを借りる必要はありません。外部サービスの利用を希望しない場合は、処理をせず導入・画面操作だけを報告して構いません。
5. Geminiを利用する場合、最初の変換では翻訳をGemini、音声をPiperにします。Piperの音声生成はPC内ですが、Gemini翻訳は文字起こしテキストをGoogleへ送信します。文字起こしモデルは初回ダウンロードがあるため、初回は時間がかかります。
6. [ユーザーガイドの初回処理](USER_GUIDE.md#3-初めての動画を処理する)に従い、元動画と出力先を指定します。「日本語字幕」「英語字幕」は空欄にします。
7. 「翻訳開始(キューに追加)」を1回押して待ちます。長時間進捗が同じでも、連打や強制終了はせず、状態・経過時間を記録してください。
8. 「完了」になったら出力先を開き、完成動画を再生します。

字幕は映像への焼き込みではなく、表示を切り替えられる字幕トラックです。再生ソフトの「字幕」「Subtitles」から英語を選びます。対応していない場合は、担当者へ相談するか[VLC公式サイト](https://www.videolan.org/vlc/)から入手したプレーヤーを使います。VLCでは「字幕」→「字幕トラック」、QuickTime Playerでは「表示」→「字幕」を確認します（名称は版によって異なります）。**字幕の開始～終了時刻以外には表示されません。** 表示されないだけで再処理を始めないでください。

## 4. 確認してほしい項目

できたものだけで構いません。できない操作は「未実施」または「分からなかった」と報告してください。

| 順番 | 確認すること |
| --- | --- |
| 1 | ダウンロード・ZIP展開・インストールが分かりやすいか。警告が出たか |
| 2 | アプリが起動し、初回設定と「利用上の注意・規約」を開けるか |
| 3 | 短い動画を登録し、待機・処理中・完了の状態が確認できるか |
| 4 | 指定した出力先に完成MP4・英語SRT・日本語SRTがあるか |
| 5 | 映像が末尾まで再生でき、英語音声が聞こえ、字幕をオンにすると表示されるか |
| 6 | 翻訳・発音・字幕の時刻に気になる箇所があるか |
| 7 | 処理完了後にアプリを閉じて開き直し、履歴と出力先が残るか |
| 8 | 余裕があれば、別のテストジョブをキャンセルして状態が落ち着くか |
| 9 | テスト終了後、必要な出力を保管し、[アンインストール手順](INSTALL_BUNDLED.md#6-保存場所更新アンインストール)を実施できるか |

キャンセルはテスト用ジョブだけで試してください。初回変換の正常完了を確認してからで十分です。データフォルダーの手動削除や、モデルの削除は依頼していません。アンインストールは任意で、設定・履歴が残る場合があります。

## 5. 担当者への報告テンプレート

次をコピーし、分かる範囲を埋めて、担当者が指定した連絡先へ送ってください。公開Issueへ動画・ログ・画面画像をそのまま投稿しないでください。

```text
テスト日：
OSと版（例：Windows 11／macOS 15）：
PCのCPU／チップ（分かる範囲）：
受け取ったセットアップ／DMGのファイル名：
担当者から案内されたActions Run番号（分かれば）：
使用した翻訳／音声（例：Gemini／Piper）：
動画の長さ（動画本体は添付不要）：
インストール：成功／失敗／未実施
起動・初回設定：成功／失敗／未実施
動画処理：成功／失敗／未実施
英語音声：確認できた／問題あり／未確認
字幕表示：確認できた／問題あり／未確認
使用した再生ソフト：
再起動・キャンセル・アンインストール：実施した項目と結果
難しかった操作／マニュアルの分からなかった説明：
問題が起きるまでの操作：
表示されたエラー（そのままの文言）：
発生時の状態・進捗・経過時間：
繰り返すと同じ問題が起きるか：
```

APIキー、パスワード、メールアドレス、講義内容、個人名・学籍番号は報告に含めません。画面画像ではこれらを隠してください。ログには動画パスや文字起こしなどが含まれ得るため、まずエラー文と操作を報告し、担当者が必要な範囲を指定してから内容を確認して共有します。元動画や完成動画の共有は、権利・個人情報・所属先の規則を確認した場合だけにしてください。

## 6. 配布担当者の準備

- 成功した同一Actions RunのOS別成果物を使い、チェックサム・同梱ライセンス・対応ソースを確認します。ビルド成功だけで一般公開の承認とは扱いません。
- 担当者がActions成果物をダウンロードし、セットアップ／DMGを取り出して協力者へ直接渡します。インストールに使うファイルを1つ明示し、Windowsのportable版は今回使わないと伝えます。
- 同じRunの3種類の対応ソース、チェックサム、ビルド情報をWeb上の共有先へ置き、入手先のリンクを案内します。インストーラーへの添付や、協力者によるダウンロードは不要です。Actions成果物は通常14日で期限切れになるため、Actionsのリンクだけに頼らず必要なファイルを保存し、共有先で取得できる状態を保ちます。
- この案内と参照先の文書を同じフォルダー構成で共有するか、版を固定した閲覧リンクを案内します。Markdownを読めない協力者にはブラウザーで読めるリンク、またはリンク先も読めるPDF等を用意します。
- テスト段階の配布は担当者本人から直接行います。依頼文にOS、ファイル名、アプリ版、Actions Run番号、未署名・検証状況、連絡先を記入し、この案内の個別許可手順でテストを進めてよいことを伝えます。APIキーを添付しません。
- テスト版の再配布や業務利用は今回の依頼範囲外と伝えます。これは新しいソフトウェアライセンス制限を設けるものではありません。
- マニュアルだけを後から更新した場合、配布物内の文書は変わりません。外部で共有する文書の版を明示し、コードが異なる版や別Runの対応ソースを混ぜないでください。
