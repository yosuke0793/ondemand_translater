# ondemand_translater

日本語音声のMP4動画から、英語音声と英語字幕付きのMP4動画を作るデスクトップアプリ「Translate Service」です。macOSとWindows向けのインストーラーを用意しています。

## 主な機能

- 日本語音声の文字起こし、英語翻訳、英語音声生成
- GUIから動画を1本ずつ登録し、登録順に処理
- 指定した出力先へ `元ファイル名_translated.mp4` と英語・日本語SRTを保存
- 日本語SRT／英語SRTを使った工程スキップ
- 音声選択、文字起こしの速度・精度プリセット、専門用語CSVの入出力
- 進捗・処理段階・履歴の表示
- APIキーの画面入力とOSの安全な資格情報保存（Windows／macOS）
- 正常完了後、指定出力以外のジョブ内動画を削除（元動画は保持）

## 利用前の注意

- 標準GUIの翻訳はGemini、音声生成はローカルのPiperです。音声合成は公式Azure AI Speechも選択できます。**翻訳やAzure選択時は外部へテキストを送信するため、完全オフラインとは限りません。** 通信先・料金・機密情報の注意は[ユーザーガイド](docs/USER_GUIDE.md#1-はじめに)を確認してください。
- 同名動画を同じ出力先へ処理すると、以前の成果物を確認なしで上書きする可能性があります。
- アプリを閉じると実行中の変換へ停止要求を送ります。終了後の処理継続は保証しません。
- エラー・キャンセルの作業用動画、動画以外の中間データ、過去の完了ジョブは一括自動削除しません。
- APIキーをコード・ログ・問い合わせへ掲載しないでください。

## 対応対象と構成

- macOS：Apple Silicon（arm64）／Intel（x86_64）
- Windows：Windows 11 24H2／25H2、x64を想定
- 標準セットアップのPython：3.10～3.13

```text
ondemand_translater/
├── docs/                用途別マニュアル
├── mac/                 macOS用インストーラー・アプリランチャー
├── win/                 Windows用インストーラー・起動スクリプト
└── source/worker/       共通GUI・ジョブ管理・変換処理
```

ソース版は各PC上でアプリ・Python環境を生成し、プロジェクト全体を保持して使います。同梱版は専用のGUI・worker・実行環境・FFmpegをまとめ、利用者のPythonに依存しません。配布用ビルドとリリース手順は [PACKAGING.md](docs/PACKAGING.md) を参照してください。ビルド経路の実装と、正式な配布物の公開・実機検証は別です。
